# **App Name**: Saree Dukan

## Core Features:

- User Authentication: Allow users to browse without accounts. Enable specific email (bp.brpl@gmail.com) to gain admin privileges.
- Product Display: Showcase sarees with images, descriptions, and prices in a user-friendly format.
- Admin Product Upload: Enable admin to upload saree photos and details.
- Saree Dukan Generation: Using Genkit and Gemini 2.5 Flash, transform the uploaded saree photo into an image of a model wearing the saree. Admin has a tool to refine the image, if needed.
- Dynamic Image Display: Display both the original saree image and the AI-generated avatar on the product page.
- Shopping Cart: Allow users to add sarees to a cart for purchase.
- Checkout Process: Implement a secure checkout process with payment gateway integration.

## Style Guidelines:

- Primary color: Deep burgundy (#800020) to evoke a sense of tradition, luxury, and richness, reflecting the cultural heritage of sarees. This is not teal.
- Background color: Soft beige (#F5F5DC), a desaturated tint of the burgundy, which provides a neutral and warm backdrop, preventing the design from being visually overpowering. 
- Accent color: Mustard gold (#FFD700) to add vibrancy, used strategically for highlights, call-to-action buttons, and important details to capture attention.
- Font pairing: 'Playfair' (serif) for headlines to add a touch of elegance and classic style; and 'PT Sans' (sans-serif) for body text, ensuring readability and a modern contrast to the serif headlines.
- Use elegant, custom icons with subtle gold accents to represent categories, sizes, and other product attributes.
- Clean and spacious layout with high-quality saree images to showcase intricate details.
- Subtle transition effects and loading animations to enhance user experience.
